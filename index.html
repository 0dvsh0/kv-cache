Formula

For GQA and MHA: 2 x layers x KV heads x head dim x bytes x context x batch. MLA caches a compressed latent plus a RoPE key: layers x (rank + rope dim) x bytes x context x batch. Hybrid models count full-attention layers at the full context and local layers at min(context, window).

Caveats

  • FP16 is 2 bytes. FP8 and INT8 are 1 byte and halve the cache.
  • Weights, activations, CUDA graphs, allocator fragmentation, and scheduler overhead are excluded.
  • Tensor parallel divides the cache evenly. Real sharding depends on KV head count and the serving engine.
  • Advertised context is not a promise of usable context at every batch size.
